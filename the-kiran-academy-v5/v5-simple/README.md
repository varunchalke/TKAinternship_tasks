# The Kiran Academy — Simple Static Marketing Website

This version is intentionally simple and reliable.

## Files
- `index.html` — complete website
- `styles.css` — all styling
- `assets/favicon.svg` — local favicon

## Hosting
Upload these files to any static hosting provider or web server. No Node.js, database, API, form handler, or external dependency is required.

## Content
Course information is written directly in `index.html`. Replace sample course details with the academy's verified information before publishing.
